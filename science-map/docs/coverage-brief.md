# 补题说明：例题和测试题要覆盖知识点的每个要点

用户要求：每个知识点的例题、测试题数量不设上限，以“覆盖讲解里的所有要点”为准（取代 AUTHORING.md 里原来“例题 2–3 道、测试 8–10 道”的规定）。

先通读 `docs/AUTHORING.md`（字段、题型 choice/num/fill、样式、质量要求都以它为准），再参考你负责文件里现有的题目风格。

## 你的任务（只改分配给你的那一个文件，不要改 html、js、其他数据文件，不要运行 bump.py）

对文件里的**每一个知识点**：

1. **列要点**：通读 `tip` 和 `learn`，把讲到的每个独立要点列出来：每个概念/定义、每个公式及其变形和单位换算、每个规律或结论、每个实验（原理、器材、步骤、现象、结论、误差/注意事项）、每个易错点、每种常考计算类型、每种图像题。
2. **对照现有题**：看每个要点有没有例题、有几道测试题。
3. **补题**，直到：
   - 每个要点至少有 **1 道例题**（例题解析写完整过程，计算题用“已知/求/解/答”）；
   - 每个要点至少有 **2 道测试题**（易错点、中考高频点 3 道），题型多样（choice / num / fill，实验类可用共用材料 `passages`）；
   - 总数不设上限，但同一要点的几道题要换情境、换考法，不要重复。
4. 原有题保留（发现错误就顺手改对）。讲解里提到的作图、简答、实验设计如果没有 `practice`，补上。

## 质量要求（严格）

- 每道选择题只有一个正确答案，干扰项来自常见错误；解析不写选项字母。
- `num` 题：答案自己验算两遍；题干说清单位和精度；g 取 10 N/kg 要注明。
- `fill` 只用于答案短且确定的题，列出所有等价写法；化学不要让学生输入完整方程式。
- 物理数值、单位、有效数字正确；化学式、化合价、配平、反应条件正确；用人教版术语。
- 题目原创或“仿中考”，不标某年真题。

## JS 语法安全

长文本用反引号模板字符串，内容里不能出现反引号或 `${`（除非是 FIG 调用所需的模板插值，照现有写法）；单引号字符串里的撇号写 `\'`。改完用 Python 检查括号平衡（忽略字符串内字符），并重读改动区域。
