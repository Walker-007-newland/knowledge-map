## 已知的实验/内容调整（编写时注意）

- **制取氧气**：新教材只讲加热高锰酸钾、分解过氧化氢溶液两种方法；**氯酸钾制氧已删去**（易爆炸）。中考题仍可能出现，写成“拓展”。
- **质量守恒定律验证**：红磷燃烧改为**铜粉加热**（2Cu + O₂ △ 2CuO，密闭锥形瓶 + 气球，放在陶土网上加热，红色变黑）；铁与硫酸铜改用**铁丝**，并在**塞紧橡胶塞的锥形瓶**中进行；碳酸钠与盐酸、镁条燃烧仍作为“天平不平衡”的讨论实验。红磷燃烧写成“拓展”。
- **燃烧条件探究**：乒乓球碎片和滤纸片改为小木块和小煤块；白磷实验可用视频代替。
- **物质的变化**：“胆矾的研碎”改为“石蜡的熔化”。
- 另据报道删去了“火焰温度高低对比”和“蜡烛是否溶于水”的实验。
- **用语**：“石棉网”改为“陶土网”。
- **中和反应**：定义仍是“酸与碱作用生成盐和水的反应”，实质 H⁺ + OH⁻ → H₂O；位于第十单元课题 2；复分解反应在其后的课题 3。
