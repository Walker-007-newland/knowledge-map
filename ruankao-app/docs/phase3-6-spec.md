## 第 3 阶段：计算机基础

### 组 A：`os.js`（module `os`，前缀 `o-`）+ `base.js`（module `base`，前缀 `b-`）
| id | 标题 | 要点 |
|---|---|---|
| o-process | 进程与线程 | 进程状态（三态 / 五态）及转换；进程与线程区别；进程间通信方式 |
| o-sched | 处理机调度 | FCFS、SJF、优先级、时间片轮转、多级反馈队列；周转时间计算 |
| o-mem | 存储管理 | 分区、分页、分段、段页式；逻辑地址 → 物理地址计算；快表 |
| o-vm | 虚拟存储与页面置换 | 局部性原理；OPT、FIFO、LRU 缺页次数计算；抖动；Belady 异常 |
| o-file | 文件管理 | 文件结构、索引分配（直接 / 一级 / 二级间接，最大文件长度计算）；位示图计算；目录 |
| o-device | 设备管理 | 程序查询、中断、DMA、通道；缓冲；SPOOLING；磁盘调度（FCFS、SSTF、SCAN、CSCAN）与存取时间 |
| b-cpu | CPU 与指令流水线 | CPU 组成（运算器、控制器、寄存器）；流水线周期、执行时间、吞吐率、加速比计算 |
| b-memory | 存储层次与 Cache | 存储层次；Cache 映射方式（直接、全相联、组相联）；命中率与平均访问时间；替换算法 |
| b-arch | 体系结构分类 | Flynn 分类（SISD、SIMD、MISD、MIMD）；CISC 与 RISC；多核 |
| b-bus | 总线与 I/O 接口 | 总线分类、带宽计算；常见接口 |
| b-check | 校验码 | 奇偶校验、海明码（校验位个数计算）、CRC（检错、模 2 除法） |

### 组 B：`db.js`（module `db`，前缀 `d-`）
| id | 标题 | 要点 |
|---|---|---|

| d-sql | SQL | DDL / DML / DCL；分组与 HAVING；视图、索引；授权 GRANT / REVOKE |
| d-trans | 事务与并发控制 | ACID；丢失修改、不可重复读、读脏数据；封锁协议（一、二、三级）、两段锁；隔离级别 |
| d-recovery | 备份与恢复 | 冷备 / 热备；完全、差量、增量备份；日志与故障类型（事务、系统、介质） |

| d-nosql | NoSQL 与新型数据库 | 键值、列族、文档、图数据库；与关系库的比较；内存数据库 |
