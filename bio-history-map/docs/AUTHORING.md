# 生物·历史知识图谱：内容编写规范

面向一个福建初中生自学用，电脑上看。教材：**新版人教版生物学**（2024 年起，七上、七下、八上、八下）；**新版统编版历史**（2024 年起，七上～九下）。目录以 `docs/bio-new-edition.md`、`docs/history-new-edition.md` 为准。讲解口语化、面向学生，用“你”。

## 文件

- 生物内容：`biology/*.js`；历史内容：`history/*.js`。每个文件形如
  ```js
  KG.nodes.push({ ...知识点1 }, { ...知识点2 });
  ```
  新文件要在 `biology.html` / `history.html` 的 `app.js` 之前加 `<script>`。
- 示意图直接写内联 `<svg>`（颜色用 `currentColor` 或中性色，深色模式下也要看得清），文字用 `<text>`，不要用外部图片。

## 知识点字段

| 字段 | 说明 |
|---|---|
| `id` | 生物 `b-xxx`，历史 `h-xxx`，小写短横线 |
| `title` / `short` | 完整名 / 图上显示名（≤ 8 个字） |
| `module` | 见各科 `modules.js` |
| `term` | 生物 `7a` `7b` `8a` `8b`；历史 `7a` … `9b` |
| `chapter` | 新版教材的单元/章名或课名，如 `'第二单元 第3课 秦统一中国'` |
| `freq` | 中考考频 1–3 |
| `keywords` | 可选，搜索用的别名 |
| `prereqs` | 前置知识点 id 数组（只能指向同学期或更早学期） |
| `tip` | 中考提示，一句话：常考形式、易错点 |
| `learn` | `[{h: 小标题, html}]` |
| `examples` | 例题，题型同 tests，解析写完整思路 |
| `tests` | 测试题，得分率 80% 算掌握 |
| `practice` | 可选：识图题、简答、材料论述（不计分，自查），见下 |
| `passages` | 可选：多题共用的材料 `{ p1: {title, html} }`，题目写 `passage: 'p1'`；共用材料的题在测试中保持相邻 |

**题量**：每个要点（讲解里每个小标题下的每个考点）至少 1 道例题、至少 2 道测试题，易错/高频点 3 道。不设上限，也不要凑数。

## 讲解里可用的样式

- `<div class="key">…</div>` 重点结论；`<p class="warn">…</p>` 易错提醒
- `<table class="tbl">` 表格（比较类知识最好用表格：动植物细胞、三种血管、两次鸦片战争……）
- 历史：`<ul class="timeline"><li><span class="yr">1840 年</span>鸦片战争爆发</li></ul>` 时间轴；`<div class="source">史料原文<span class="from">——《史记·秦始皇本纪》</span></div>` 史料引文
- 生物：内联 `<svg>` 结构示意图（细胞、心脏、花……），各部分标注名称

## 题型

```js
{ type: 'choice', q: '题干 html', options: ['…','…','…','…'], answer: 正确下标, explain: '…' }
{ type: 'fill', q: '…', answer: ['可接受答案1', '答案2'], explain: '…' }
{ type: 'num', q: '…', answer: 25, unit: '%', explain: '…' }          // 生物遗传概率等
{ type: 'open', q: '…', ref: '参考答案 html', points: [{s: 2, p: '得分要点'}, …], explain: '可选补充', rows: 4 }
```

- **选项会被打乱**：解析里不能写“选 A”“第二项”“最后一项”，要说内容。选项里不要出现“以上都对”“A 和 B”。组合选项（①②、②④……）加 `fixed: true`。
- **`fill`**：只用于答案很短且唯一的题（一个术语、一个年份、一个人名、一个条约名）。比对时忽略空格、引号书名号、句末标点。把常见等价写法都列进 `answer`（如 `['胚珠']`、`['1840', '1840年']`）。
- **`open`（主观题）**：历史材料分析、生物简答/实验探究。学生交卷后对照 `ref` 自评、勾 `points`，按得分折算。要点要能逐条判断“答到/没答到”，每条写清关键词，如“答出‘控制变量唯一’（或‘只有光照不同’）”。分值 1–3 分一条。
- 每道客观题必须**只有一个正确答案**，干扰项来自学生常见错误。有争议的说法（史学界有分歧的评价、教材新旧版表述不同的概念）不出唯一答案题。
- 题目一律原创或“仿中考”，不标某年真题。材料题的史料可以用真实史料原文（注明出处），但要准确，不能编造引文；不确定原文就用自己概述的“材料”。

## 中考特色

- 福建卷爱考乡土情境：生物——武夷山、福建茶、红树林、厦门白鹭、中华白海豚；历史——林则徐（福州）、福州船政、严复、郑成功收复台湾、泉州海上丝绸之路、古田会议、长汀等。适当使用，事实必须准确。
- 生物重视实验探究（变量、对照、结论）和识图；历史重视时空观念（时间轴、阶段特征）、史料实证、因果关系和评价。

## 识图·简答 / 材料·论述（practice）

```js
practice: [{ title: '标题', prompt: '题目 html', write: true,
             sample: '参考答案 html', checklist: ['评分要点1', '…'], notes: '可选补充' }]
```
`write: true` 时给一个文本框（自动保存）。不计分，用来练开放性更强的题（如“评价某历史人物”“设计一个探究实验”）。

## 质量要求

- 生物：概念用新版人教版用语（如“生物学”“结构层次”“生态系统”）；遗传题的基因型、比例要能验算。
- 历史：年代、人名、地名、条约内容、事件顺序准确；评价用教材口径，客观全面。
- 不确定的事实不要写；宁可少写。
