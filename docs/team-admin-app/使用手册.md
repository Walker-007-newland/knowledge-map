# 「团队审批」App 使用手册

这篇写给管理员，讲手机上的「团队审批」App 怎么装、怎么设置，以及审批、办公室、节点页（学生账号、注册码、同步组、日志）、网页登录设置和自动更新怎么用。

---

## 一、安装和首次设置

### 安装
- 下载地址（带版本号，国内可用）：`https://cdn.jsdelivr.net/gh/Walker-007-newland/knowledge-map@admin-v<版本>/team-admin.apk`，当前版本见《[更新说明](更新说明.md)》。
- 每次发布后电脑上会生成二维码 `team-admin-app/out/team-admin-qr.png`，手机扫码下载即可。
- 已装过的直接覆盖安装，token 和设置会保留。

### 设置 GitHub token（必须）
App 通过 GitHub 读写团队看板（私有仓库 `Walker-007-newland/knowledge-map-team` 的 Issue）。第一次打开会进「设置」页（右上角 ⚙ 也能进）：

1. 电脑浏览器打开 github.com → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token
2. Repository access 选 **Only select repositories** → `Walker-007-newland/knowledge-map-team`
3. Permissions → Repository permissions → **Issues: Read and write**（Metadata 自动只读）
4. 生成后复制，粘到 App 的「Token」框，点「保存并检查」，提示「连接成功」即可

> token 只存在手机本机。请用这种只限看板仓库的细粒度 token，**不要**用电脑上 `knowledge-map-app/signing/` 里那份权限很大的 token。

## 二、主界面

顶部一行：「‹ 返回」、标题、「＋ 需求」（提一个需求）、「刷新」、「⚙」（设置与更新）。
下面是六个标签：

| 标签 | 内容 |
|---|---|
| 办公室 | 团队每个成员现在在做什么（像素小人） |
| 节点 | 同步节点管理（见第五节）；节点需要注意时标签上有红点 |
| 待审批 | 状态为「待审批」「阻塞」的需求单——需要你（或 AI 代审）处理的 |
| 进行中 | 已批准、开发中、待测试、返工、需修改 |
| 待评审 | 需求员刚提、等产品评审的 |
| 已结束 | 已关闭的单（已上线、已驳回、产品否决） |

点一张单进入详情：能看到需求正文和全部评论（产品方案、开发说明、测试报告、已上线等），最新的方案会标出「最新方案」。

## 三、审批

> 2026-10-16 起审批默认由 AI 代审（评论首行写「（AI 代审）」），规则见《[AI 团队说明](../team/AI团队说明.md)》。你随时可以在 App 里推翻：在单子上再批准 / 要求修改 / 驳回即可。

在详情页底部的意见框写意见（批准可以不写；要求修改、驳回、交回时请写原因），然后点按钮。每个操作会先问「确定……？」。

**「待审批」的单：**
| 按钮 | 效果 |
|---|---|
| 批准 | 评论「管理员审批：批准」，状态改为「已批准」，开发下一轮接手 |
| 要求修改 | 评论「管理员审批：要求修改」，状态改为「需修改」，退回产品 |
| 驳回 | 评论「管理员审批：驳回」，状态改为「已驳回」，产品下次关闭它 |

**「阻塞」的单**（卡住等人处理，评论里会写清需要你做什么）：
| 按钮 | 效果 |
|---|---|
| 交回开发 | 评论「管理员处理阻塞：交回开发」，状态改为「已批准」 |
| 交回测试 | 状态改为「待测试」 |
| 让产品改方案 | 状态改为「需修改」 |
| 驳回 | 状态改为「已驳回」 |

**其它状态的单**：可以「只发评论」（评论标题「管理员评论」）或「驳回 / 不做了」。

### 自己提需求
点顶部「＋ 需求」，填「标题」和「想要什么、为什么」，提交后进入「待评审」，产品会评审。

### 待审批提醒
App 在后台大约每 30 分钟检查一次，出现新的（或有更新的）待审批、阻塞单时发系统通知「有 N 个需求等你处理」（通知类别名「待审批提醒」）。同一批单不会重复提醒。

## 五、节点页（管理同步节点）

「节点」管的是腾讯云服务器上的同步节点（km-sync），它保管学生的账号、给平板之间的同步做中转。

> **你能看到的**：有哪些账号（用户名、注册时间、最后登录、几台设备、占多少空间）、有几个同步组、什么时候同步过、用哪张注册码注册。
> **你看不到的**：任何学习内容、密码、哪一科有数据——节点上只有看不懂的密文和编号。

> 知识图谱 App 2026.10.23.2024 起改为**注册登录**（#12 第一期）：学生凭你在「注册码」页生成的注册码注册账号，换平板登录同一账号就拿到全部记录。以前的「邀请码」改名「同步邀请码（旧）」，只给还没升级的旧版 App 用。学生忘记密码只能由你在这里重设，重设前要先导入一次「账号恢复密钥」。

### 第一次连接（扫管理码）
1. 在电脑上打开 `knowledge-map-app/signing/sync-node-admin.png`（管理码，里面含管理密钥，**不要发给别人**）。
2. 手机 App 进「节点」页（或 ⚙ 设置 →「同步节点」），点「扫描管理码」用相机扫；也可以「从相册选图」或「粘贴文字」。
3. 提示「已保存管理码（kid …）」后，「节点」页显示「● 在线」。

管理密钥用手机系统密钥库加密保存在本机，网页拿不到。管理码格式不对时会有中文提示（如「这不是管理码（应该以 kmadmin:1? 开头）」），不会保存。

### 「节点」页的七个子页

子页顺序：状态、账号、注册码、同步组、同步邀请码（旧）、限额与访问、操作日志。

**状态**
- 节点地址、版本和已运行时间、磁盘剩余、同步组数 / 上限和总占用、近 24 小时请求和错误次数。
- **服务器到期**：显示到期日和剩余天数（≤ 14 天黄色、≤ 3 天红色）。**续费后点「改到期日」→ 选新日期 →「保存到期日」**。
- **证书**：网页后台的 Let's Encrypt 证书剩余时间（正常显示「自动续期」；剩不到 48 小时标红，此时只影响网页后台，App 和同步不受影响）。
- **网页后台**：地址和网页登录状态。
- **外网管理**：允许 / 已关闭，以及 IP 名单。
- 「刷新」按钮。
- 节点标签出红点的情况：连不上、离到期 ≤ 14 天、磁盘剩余 < 10%、证书剩不到 48 小时。

**账号**（学生账号，2026.10.23.2025 起）
- 顶部「**账号恢复密钥**」卡片：
  - 还没导入时显示「● 还没导入：不能帮学生重设密码」。在电脑上打开 `knowledge-map-app/signing/km-recovery.png`，点「扫描恢复密钥」用相机扫（也可以「从相册选图」或粘贴文字后点「保存」），**只需要一次**。导入后显示「● 已导入（编号 …）」，有「重新导入」按钮。
  - 恢复密钥用手机系统密钥库加密保存在本机；「清除」管理码时它会保留。**请把 km-recovery.png 另存一份到安全的地方，不要外传**：丢了就不能帮学生重设密码；拿到它的人能解开学生的学习记录。
- 「按用户名搜索」+ 账号列表：每行显示 👤 用户名、备注、状态（正常 / 已停用 / 待重新登录；密码错太多时还有「密码错太多，暂停中」）、注册时间、最后登录时间和设备、几台设备、占用。已停用的灰色显示。还没有账号时提示到「注册码」页生成注册码。
- 点一行进**账号详情**：
  - 基本信息：用户名、状态、注册时间和用的注册码（前 4 位）、最后登录、同步组号、占用、密码第几版（重设过会标出）。
  - 「设备（N）」：每台的名字、首次登录、最后同步、App 版本；「老设备（还没升级登录）」= 绑定账号前就在同步组里、还没用新版登录的平板；「待重新登录」= 下次联网要重新输密码。每台有「**移除这台设备**」：它下次联网时回到登录页、拿不到以后的新数据（已经在它上面的记录收不回）。平板丢了用这个。
  - 「备注（最多 40 字，如「初三 2 班 小明」）」→「保存备注」。
  - 「**重设密码**」（要先导入恢复密钥，否则提示「还没导入账号恢复密钥，不能重设密码」）：填「新密码（8 位以上，字母加数字）」或点「生成临时密码」，点「重设密码」，确认后提示「已重设，新密码：…（请告诉学生）」。重设后这个账号所有平板下次联网时回到登录页（学习记录都在），用新密码登录。新密码只在你手机屏幕上出现一次，请当场记下来告诉学生。
  - 「**停用账号**」/「**启用账号**」：停用后这个账号的平板不能再同步（本机学习记录还在），平板提示「账号已被管理员停用」；启用后学生重新输入密码登录。
  - 「**删除账号**」（只在 App 里有）：删掉账号和它在服务器上的全部数据，**不能撤销**，要输入用户名确认；平板上的学习记录不受影响。主要用来清理测试账号。
- 节点还是 1.3.0 时这一页提示「账号要节点 km-sync 1.4.0 以上」。

**注册码**（2026.10.23.2025 起）
- 「生成注册码」：填备注（最多 20 字，如孩子的名字）、有效期（1 / 7 / 30 / 90 天，默认 30）、可用次数（1 / 2 / 3 / 5 次，默认 1），点「生成」。屏幕显示大二维码和「XXXX-XXXX-XXXX」文字，学生在知识图谱 App 登录页「注册」里扫码或输入。**每个学生一张，1 次有效**，发给学生（拍屏、截图或抄下文字都行）。
- 列表每张显示状态（有效 / 已过期 / 已用完 / 已作废）、已用次数、「注册了 👤 谁」、到期时间；可「显示二维码」「作废」。作废后不能再用它注册，已经注册的账号不受影响。
- 注册码的二维码里带着服务器地址，扫码注册的平板会自动用这个地址。

**同步组**
- 每行：组号前 6 位、邀请码备注、设备数、占用 / 上限、最后访问时间。已封禁的灰色显示。
- 点开看详情：「账号」一行显示绑定的用户名（没绑定的显示「#1 的同步组，还没升级成账号」）、设备列表（设备号前 6 位、最后同步、最后上传、分区数、占用）、创建时间、来源邀请码、上一代组号；可以改「备注」「空间上限」后点「保存备注和上限」。
- 账号的同步组一般不用在这里操作，到「账号」页处理。
- 按钮：
  - 「清空数据」：删掉这个组在节点上的数据，组保留；设备下次同步会自动重新上传，学习数据在设备上，不会丢。
  - 「移除并封禁」：删组并封禁，这个组的设备不能再用同步节点。如果是陌生组，建议同时作废它用的邀请码。
  - 「解除封禁」（已封禁的组才有）：设备下一轮会自动重建并重新上传。
  - 「**彻底删除登记**」（已移除并封禁、节点上没有数据的组才有）：让这个组从列表里消失；组号永久封禁，**不能再解除封禁**，设备也不能用邀请码把它重建出来。这一步**不能撤销**，会记进操作日志。用来清理不再需要的已封禁空组；如果是陌生组，记得同时作废它用的邀请码。

**同步邀请码（旧）**
- App 改成账号登录后，学生用「注册码」注册，一般不再需要这种邀请码；只给还没升级的旧版 App 建同步组用。
- 「生成同步邀请码（旧）」：填备注（最多 20 字）、有效期（1 / 7 / 30 天）、可用次数（1 / 3 / 10 次），点「生成」，屏幕显示大二维码，可「复制文字」。
- 列表每张显示状态（有效 / 已过期 / 已用完 / 已作废）、已用次数、建了几个组、到期时间；可「显示二维码」「作废」。
- 作废后不能再用它建新组，也不能凭它重建；已在用的组不受影响，要停掉就再移除组。
- 初始邀请码图片在电脑 `knowledge-map-app/signing/sync-node-invite.png`。

**限额与访问**
- 限额：最多组数（默认 300，每个账号一个组；1.3.0 及以前默认 30）、每组默认空间 MB（1–500，默认 50）、单分区 MB（默认 4）、单请求 MB（默认 8）、每 IP 每 10 分钟次数（默认 600）→「保存限额」。
- 管理访问：
  - 「允许外网管理」开关：关掉后手机「节点」页就用不了，只能在电脑上经 SSH 隧道管理；恢复要在电脑上运行 `deploy.ps1 -ResetAdminAccess`（见《[运维手册](../sync-node/运维手册.md)》）。
  - 「只允许这些 IP / 网段」：每行一个，空着 = 不限（手机 IP 经常变，一般不用填）。名单里不包含你当前 IP 时不能保存，免得把自己锁在外面。→「保存访问设置」
- **网页登录**（只在 App 里有，见第六节）。

**操作日志**
- 最近 50 条，「更多」翻页；勾「只看安全事件」只看认证失败、封 IP、熔断。
- 「谁」一栏：`管理员 <kid>` = App 操作；`网页 <用户名>（会话 xxxx）` = 网页后台操作；`系统` = 节点自己。
- 账号相关的操作（生成 / 作废注册码、停用、启用、移除设备、重设密码、改备注、删除账号）都会记一条，写着对哪个用户名做了什么。
- 「**导出全部日志（CSV 文件）**」：把节点上的全部日志导出成一个表格文件（勾了「只看安全事件」时按钮变成「导出安全事件」，只导安全事件）。会弹出系统「保存到」，选个位置保存，用 WPS / Excel 打开。文件名形如 `km-sync-log-<日期>-<时间>.csv`。节点只保留最近 90 天的日志，需要长期留存就定期导出。

**连不上时**
显示「● 连不上同步节点」和原因，点「重试」。超时一般是服务器停了 / 到期了，或腾讯云防火墙没放行 TCP 8787；「节点拒绝了请求（403）」一般是管理码失效（换过管理密钥）或当前网络 IP 被封。处理办法见运维手册「故障处理」。

### 设置页的「同步节点」
显示地址和管理码 kid，四个按钮：
- 「重新扫码」：电脑上换过管理密钥（`deploy.ps1 -NewAdminKey`）后用，扫新的管理码。
- 「**改节点地址**」：服务器搬家（比如从腾讯云搬到家里的电脑 / NAS）后，填新地址（如 `192.168.1.20:8787`）。管理密钥不变，不用重新扫码。搬家步骤见《[运维手册](../sync-node/运维手册.md)》第九节。
- 「**换管理密钥**」：在手机上直接换一把新的管理密钥。这台手机自动换上新的，**旧的立即失效**：电脑上的 `signing/sync-node-admin.png`、其它装了审批 App 的手机都不能再管理节点；网页后台的密码和登录不受影响。换好后提示「已换成新的管理密钥（kid …），旧的已失效」，设置页的 kid 随之变化。适合怀疑管理码图片外泄、或手机被别人用过时用。以后电脑上需要管理码，就在电脑上运行 `deploy.ps1 -NewAdminKey` 重新生成，那时这台手机也要重新扫码（见《[运维手册](../sync-node/运维手册.md)》）。
- 「清除」：清除本机保存的管理码，节点本身不受影响。

下面的「**节点提醒**」一块说明后台通知规则（见下一小节）。

### 同步节点提醒（后台通知）
App 在后台大约每 30 分钟检查一次节点（和待审批提醒一起），出现下面情况时发系统通知「同步节点提醒」，**每类每天最多一次**：

| 情况 | 怎么处理 |
|---|---|
| 连续两次连不上（包括被节点拒绝，如管理码失效、IP 被封，原因写在通知里） | 按上面「连不上时」和运维手册「故障处理」 |
| 磁盘剩不到 10% | 「同步组」里清空或移除不用的组，或调低每组空间上限 |
| 离服务器到期 7 天以内（含已过期） | 去腾讯云续费，续费后「状态 → 改到期日」 |
| 网页后台证书剩不到 48 小时 | 只影响网页后台，App 和学生同步不受影响；让开发按运维手册检查证书续期 |

不想收这类通知，可以在手机系统设置里单独关掉「同步节点提醒」这一类（不影响「待审批提醒」）。

## 六、网页登录设置（网页后台的账号在这里管）

网页后台（电脑浏览器打开 https://43.142.41.27 ）的用户名和密码只能在 App 里设，App 的管理码是「总钥匙」。位置：「节点」→「限额与访问」→「网页登录」。

- **第一次设置**：填「用户名（3–32 位字母或数字）」、「密码（至少 12 个字符；不要和别的网站共用）」、「再输一次」，点「设置密码并打开网页登录」。页面会实时提示密码强度。
- 「允许网页登录」开关：临时关闭 / 打开网页登录。
- 「重新设置密码」：忘了网页密码时用，所有网页会话会失效。
- 「关闭二次验证」：手机验证器丢了时用，之后网页只要用户名和密码。
- 会话列表：看到每个网页登录的时间、IP、浏览器、最后使用，可「踢下线」或「全部踢下线」。
- 「重置网页登录」：清空网页的用户名、密码和二次验证，踢掉所有会话，网页登录关闭；之后要重新设密码才能登录。

怀疑网页密码泄露：先「全部踢下线」，再「重新设置密码」。网页上不能改这里的任何设置，也不能关「外网管理」。网页后台怎么用见《[网页后台使用手册](../web-admin/使用手册.md)》。

## 七、自动更新

- 每次打开 App 会自动检查新版本，有新版弹出「发现新版本」，显示版本和说明，点「立即更新」下载安装（覆盖安装，token 和设置保留）。
- 手动检查：⚙ 设置 →「检查更新」。设置页顶部也显示当前版本。
- 下载失败时可「重试」或「用浏览器下载」。

### 学生账号的日常事务（速查）
| 学生说 | 你做 |
|---|---|
| 要注册 | 「节点 → 注册码」生成一张（默认 30 天 1 次），发给学生 |
| 忘记密码 | 「节点 → 账号」点开该账号 →「重设密码」（第一次要先导入恢复密钥），把新密码告诉学生 |
| 平板丢了 | 账号详情里「移除这台设备」；不放心就「停用账号」，找回后「启用账号」 |
| 换了新平板 | 不用你做：学生在新平板登录同一账号即可 |
| 提示「账号已被管理员停用」 | 账号详情里「启用账号」 |
