# 知识图谱 App 使用手册

这篇写给使用「知识图谱」平板 App 的学生和家长，讲怎么安装、怎么学、怎么养小狗、怎么备份学习数据，以及怎么让几台设备自动同步。

---

## 一、安装和更新

### 第一次安装
1. 用平板浏览器打开家长或管理员给的下载地址（或扫二维码），下载「知识图谱」安装包。
2. 打开下载好的安装包。第一次安装时，平板可能会提示「是否允许安装未知来源应用」，按提示允许即可。
3. 装好后，桌面上会出现「知识图谱」图标。App 不用联网也能学习。

### 更新到新版本
- **自动提示**：联网时打开 App，如果有新版本，会弹出「发现新版本」窗口，显示当前版本、最新版本和这次更新了什么。点「立即更新」下载并安装；不想现在更新就点「以后再说」。
- **手动检查**：总入口页面最下面有「检查更新」按钮，点一下就会检查。已经是最新版时会提示「已经是最新版本」。
- 更新是**直接覆盖安装**，学习进度、错题本、小狗都会保留，不用卸载旧版。
- 如果提示「所有下载线路都连不上」，可以稍后重试，或点「用浏览器下载」，下载后手动安装（同样直接覆盖）。

> 提示：不要先卸载再安装——卸载会把这台平板上的学习数据一起删掉。实在要卸载，请先到「我的数据」导出一份备份（见第八节）；加入了同步组的话，卸载后要重新扫加入码加入（见第九节）。

## 二、总入口

打开 App 先看到的是总入口：

- **小狗卡片**（最上面）：还没领养时写着「领养一只小狗」；领养后显示小狗的名字、等级、饱食度、骨头数和「今天学习 X 分钟」。有骨头没领时右边会出现「+N 🦴 待领取」，桌面上还没放小狗时会出现「📌 把小狗放到桌面」。点卡片进入宠物页。
- **各科卡片**：
  - 主科：数学（三年级 → 九年级）、语文（四年级 → 初三）、英语（四年级 → 初三）
  - 理科：物理（八年级上 → 九年级）、化学（九年级上 → 九年级下）
  - 生物 · 历史：生物（七年级上 → 八年级下）、历史（七年级上 → 九年级下）
  - 其它技能：学做笔记（康奈尔 · 导图 · 错题本）
- **右上角的同步标签**：只有加入了同步组才会出现，显示「✓ 已同步」「⟳ 同步中」「待同步」或「⚠ 同步出错」，点它进入设备同步页（见第九节）。
- **最下面一行**：版本号、「💾 我的数据」（备份和合并学习数据）、「🔄 设备同步」、「检查更新」。

## 三、各科图谱怎么学

每一科都是一张「知识地图」，一个圆点就是一个知识点，连线表示先学哪个、后学哪个。

### 看地图
- 用手指拖动地图，双指捏合放大缩小；右下角也有「+」「−」和「适应窗口」（⤢）按钮。
- 圆点的颜色表示学到哪了（地图角落有图例）：
  - 语文、英语、物理、化学、生物、历史、学做笔记：**未学**、**学习中**、**需加强**、**已掌握**；带 ★ 的是中考考频。
  - 数学：**已掌握**、**再练练**、**没掌握**。
- 顶部有搜索框，输入关键词（比如「勾股」）就能找到知识点。

### 学一个知识点
点地图上的知识点，会打开全屏的学习页，按标签切换：

| 科目 | 标签 |
|---|---|
| 语文、英语 | 讲解、例题、写作练习、测试 |
| 物理、化学、生物、历史、学做笔记 | 讲解、例题、作图·简答（或类似练习）、测试 |
| 数学 | 动画讲解、例题、测一测 |

一般顺序是：先看讲解 → 看例题 → 做练习 → 做测试。

### 怎样算「已掌握」
- 语文、英语、物理、化学、生物、历史、学做笔记：测试正确率达到 **80%** 就算掌握；在「入门诊断」里直接测过的也算。
- 数学：「测一测」最好成绩达到 **80%** 算掌握（50% 以上显示「再练练」）。
- 每掌握一个新知识点，就能给小狗领 3 根骨头（见第六节）。

### 主观题怎么给分（自评）
语文、英语、理科、生物历史里有些题没有唯一答案（比如简答、作文类）。交卷后页面会提示「还差最后一步：自评」：对照每道题的参考答案，把你答到的要点勾上（意思对就算，不要求字字相同），最后点「**自评完成，出成绩**」。主观题的分数按你的自评折算。请诚实自评，这样地图颜色才准。

### 顶部的其它按钮
- **入门诊断**（语文、英语）/ **诊断测试**（物理、化学）：先做一套诊断题，系统帮你判断哪些知识点已经会了，不用从头学。
- **学习路线**（语文、英语）/ **学习路径**（物理、化学）：按推荐顺序列出要学的知识点。
- **下一步学什么**（数学叫「接下来学什么 →」）：直接告诉你现在最该学哪一个。
- **错题本**（数学）：测一测做错的题会自动记进来，在错题本里订正答对就会移出。
- **备份进度**：只导出/导入**这一科**的进度。要一次备份全部科目，请用总入口的「我的数据」（第八节）。
- 物理页右上角「切换到化学 →」、生物页「切换到历史 →」可以在两科之间切换。

### 写作练习的草稿
写作练习里写的文字会自动保存成草稿，下次打开还在。

## 四、听讲解（语音朗读）

在知识点的讲解页，上方有一条播放条：
- 「🔊 听讲解」开始逐段朗读，读到哪一段就高亮哪一段；读的时候按钮变成「⏸ 暂停」。
- 「⏮」「⏭」上一段、下一段。
- 语速按钮可以在 0.8、1、1.25 倍之间切换，App 会记住你的选择。
- 切换标签或关掉学习页会自动停止朗读。
- 朗读用的是平板自带的中文语音，不用联网。

## 五、英语单词听写

在英语图谱顶部点「**单词听写**」：

1. **建词单**：点「📷 拍照新建词单」拍课本上的单词表（也可以「🖼️ 从相册选」），App 会自动识别单词和中文意思；也可以点「✍️ 手动输入」。
2. **确认**：识别完逐个检查，没把握的会标黄；可以「＋ 添加一个词」、改错、删掉不要的，填好「词单名称」后点「保存词单」。
3. **设置听写**：选范围（全部 / 错词 / 「随机抽」几个）、作答方式（「纸上写」或「键盘输入」）、读法（「读英文」「英文 + 中文」「读中文写英文」）、遍数（1–3 遍）、书写时间（快 / 中 / 慢）、顺序（随机 / 按词单）。点「开始听写」。
4. **听写中**：屏幕只显示序号，读完自动倒计时；可以「⏮ 上一个」「🔁 再读一遍」「⏸ 暂停」「下一个 ⏭」「结束听写」。听写时屏幕不会自动熄灭。
5. **批改**：纸上写的自己对照批改后点「批改完成」；写错的词自动进错词本，下次写对一次就移出。可以「全部再听一遍」或「错词再听写」。
6. 点「← 返回」回到英语图谱。

> 识别是在平板上离线完成的。短语（如 get up）偶尔会被认成一个词，保存前在确认页改一下就好。

## 六、小狗

### 领养
总入口点小狗卡片 → 选品种（柴犬或哈士奇）→ 「给它起个名字」（最多 8 个字）→ 「领养它」。

### 骨头从哪来
- 在任何一科**掌握一个新知识点**，就能领 **3 根骨头**，同一个知识点只能领一次。
- 掌握时会当场弹出领骨头的提示；也可以在宠物页点「领取」。

### 照顾它
- 「🦴 喂食」：花 1 根骨头，饱食度 +20。小狗每天会慢慢变饿，饿了会没精神，但**不会生病**。
- 「🤚 摸摸」「🎾 扔球」：陪它玩，心情会变好。当天学满 10 分钟、30 分钟，心情也会更好。
- 「改名」：随时可以给小狗改名。

### 长大和装扮
- 掌握的知识点越多，等级越高。小狗会从幼犬长成少年犬、成年犬、学霸犬。
- 「装扮」标签里可以用骨头买项圈、帽子、眼镜、书包、披风等，等级越高解锁越多；买到后点一下穿戴，再点取下。
- 「成长记录」标签里能看到它的成长历程。

### 把小狗放到桌面
宠物页名字旁边点「放到桌面」。如果系统弹出「添加到桌面」的窗口，点「添加」即可。
很多平板不会弹窗（安卓不允许 App 自己把小狗放上桌面），这时页面会显示适合你这台平板品牌的**手动添加步骤**，一般是：长按桌面空白处（或双指捏合）→ 小部件 / 小组件 → 找到「知识图谱」→ 把小狗拖到桌面。也可以按提示点「打开本应用设置」，打开「桌面快捷方式」权限后再点「放到桌面」。
放好以后，重启平板小狗也会一直在桌面上，点它就能打开宠物页。

## 七、学习统计

宠物页顶部点「📊 学习统计」，可以看到：
- **每天学习时长**：每天在各科学了多少分钟（只有在学习页面、并且最近几分钟有操作时才计时）。
- **各科进度**：每科掌握了多少知识点。
- 连续学习了多少天。

## 八、我的数据（备份、换平板、合并）

总入口最下面点「💾 我的数据」（宠物页顶部也有）。

### 本机数据
页面最上面列出这台平板上的数据：每科「已掌握 X / 有记录 Y 个知识点」、数学错题本、草稿、学习总时长、小狗、单词听写词单，以及这台设备的名字。

### 导出全部学习数据
点「**导出全部学习数据**」，所有科目的进度、数学错题本、作文草稿、入门诊断、学习时长、小狗、单词听写词单都会存进**一个文件**，放在平板的「下载 / 知识图谱」文件夹里，文件名类似「知识图谱-全部学习数据-日期.json」。
**换平板、恢复出厂设置、卸载之前，一定先导出一份**，并把文件拷到电脑或网盘保存。

### 导入并合并
1. 点「选择文件…」，选一个导出的文件（以前在各科「备份进度」里导出的单科文件也可以）。
2. 页面会先显示「**合并预览**」：每类数据会有什么变化，比如「语文 新增 12 个知识点记录」「数学错题 +5、−2」「小狗 骨头 45 → 52」。没有变化时会显示「没有变化」。
3. 确认没问题点「**确认合并**」；不想合并点「取消」，什么都不会改。
4. 合并前 App 会**自动先导出一份「导入前备份」**，也放在「下载 / 知识图谱」里，万一合并结果不满意可以用它恢复。

### 合并的规则（不会覆盖）
- 成绩取更好的，不会倒退；最近一次测试的结果以较新的为准。
- 学习时长、小狗骨头**不会重复计算**，同一个文件导入两次也不会翻倍；小狗等级不会因为合并而降低。
- 在一台平板上答对删掉的错题，合并后不会再冒出来。
- 两台平板同一篇草稿写得不一样时，**两份都保留**：较新的做正文，较旧的接在后面，标着「【另一台设备 … 保存的版本】」，你可以自己再删改。
- 两台平板各养了一只小狗时，合并成一只（用最早领养的那只的名字和品种）。

## 九、设备同步（几台设备自动同步）

同一个学生如果有好几台平板（比如家里一台、学校一台），可以加入同一个「同步组」。之后学习记录、错题本、作文草稿、学习时长和小狗会自动合成一份，在哪台上学都一样，**不用在同一个 Wi-Fi 下**，只要都能上网。

入口：总入口最下面点「**🔄 设备同步**」；已经在同步的话，也可以点右上角的同步标签。

> 设备同步只能在平板 App 里用。在电脑浏览器里打开会提示去「我的数据」用导出、导入文件的办法。

### 第一台设备：扫邀请码开始
1. **先向管理员要一张「邀请码」**（一张二维码）。邀请码只在第一台设备上用一次，以后加别的设备不用再要。
2. 在设备同步页点「**📷 扫邀请码，开始同步**」，用平板相机拍下邀请码。
3. 弹出「用这张邀请码建一个同步组？」，点确定。开始前 App 会**自动备份一份本机数据**（见下面「自动备份在哪」）。
4. 建好后页面顶部显示「已同步 · 今天 时:分」。回到总入口，右上角标签先是「待同步」，过一会儿变成「✓ 已同步」。

### 加第二台（第三台…）设备：加入码 + 确认码
设备 A 是已经在同步的那台，设备 B 是要加进来的那台。
1. 在 **A** 的设备同步页点「**➕ 添加设备**」。A 屏幕上会出现一个二维码（加入码），下面还有一行文字和「还剩 X 分 X 秒」的倒计时，**10 分钟内有效**。
2. 在 **B** 的设备同步页点「**📷 扫加入码，加入我的另一台设备**」，拍下 A 屏幕上的二维码。
   - 拍不了的话，点「**扫不了？手动输入**」，把 A 二维码下面那行文字原样输进去，点「确定」。
3. B 上会显示「请在『A 的名字』上确认，确认码：四位数字」。
4. A 上会弹出「『B 的名字』要加入你的同步组」，里面也有一个四位确认码。
   - **两边的四位数字一样**，并且确实是自己的设备，就在 A 上点「**数字一样，加入**」。
   - **数字不一样、或者不认识这台设备**，点「**不是我的设备**」。这次的加入码就作废了，别人拍到二维码也加不进来。
5. 加入成功后，B 会提示「已加入…正在第一次同步…」，同样会先自动备份一份本机数据。两台原来各自的学习记录会**合并**成一份（规则和「我的数据」导入合并一样，不会覆盖、成绩不会倒退，两只小狗会合成一只，见第八节）。
6. 加入码过期（显示「加入码已过期，请重新生成」）就在 A 上再点一次「添加设备」。

> 只加入**同一个学生自己的设备**。加进来的设备能看到这个同步组里全部的学习记录。

### 平时怎么同步
- 不用手动操作：打开 App、回到总入口时都会自动同步，在前台每隔一段时间也会同步一次。
- 一台设备上学完，另一台**回到总入口**后，一般几十秒内就能看到变化，并弹出一行提示，比如「从『某某平板』同步：语文 新增 1 个知识点记录，已掌握 6 → 7；小狗 骨头 20 → 23」。
- 想马上同步，可以在设备同步页点「**🔄 立即同步**」。
- 没网的时候照常学习，连上网后会自动补齐。

### 总入口右上角的同步标签
| 标签 | 意思 |
|---|---|
| ✓ 已同步 | 本机的改动已经同步好了 |
| ⟳ 同步中 | 正在和别的设备交换改动 |
| 待同步 | 本机有新的改动还没送出去，稍后会自动同步 |
| ⚠ 同步出错 | 这次没同步成功（比如没网、同步服务器连不上）。点标签进设备同步页看原因；本机照常学习，数据不会丢 |
| （没有标签） | 这台设备没有加入同步组 |

设备同步页顶部那一行会写得更具体，比如「已同步 · 今天 18:20 · 最近收到『某某平板』的改动」「有改动等待同步」「同步节点连不上，本机照常学习，连上网后会自动补齐」。

### 自动备份在哪
第一次建组、加入同步组之前，App 会自动把本机全部学习数据导出一份，放在平板的「**下载 / 知识图谱**」文件夹里，文件名类似「**知识图谱-同步前备份-日期-时间.json**」。万一合并后不满意，可以在「我的数据」里用它恢复（见第八节）。

### 我的设备：改名、移除
设备同步页「**我的设备**」里列出这个同步组里的所有设备，标着「本机」的是你手上这台，每台都写着「上次收到它的改动」的时间。最下面一行「☁️ 同步节点」是帮忙转交数据的服务器，不是一台设备。
- 「**改名**」：给设备起个好认的名字（比如「家里的平板」），别的设备上的提示也会用这个名字。
- 「**移除**」：把一台设备踢出同步组。适合设备丢了、送人了，或者列表里出现了**不认识的设备**。
  - 移除后它不能再和你的设备同步，也拿不到以后的新数据；它上面已经有的学习记录留在它自己那里。
  - 移除时 App 会顺便**更换同步钥匙**（页面显示「正在移除…并更换同步钥匙…」），其它设备自动换上新钥匙，不用你操作。

### 退出同步组
设备同步页最下面「其它」里点「**退出同步组**」：这台设备以后不再和别的设备同步，**本机学习数据全部保留**。以后想再加入，就在已在同步的那台设备上点「添加设备」，在这台上扫加入码。

「其它」里还有「**📷 重新扫邀请码**」：只有提示「邀请码已失效」或管理员说同步服务器换了地址时才用，用管理员给的新邀请码扫一下，同步组和数据都不变。

### 各种提示是什么意思
| 提示 | 意思 | 怎么办 |
|---|---|---|
| 这台设备已被移出同步组，本机数据还在 | 你的另一台设备在「我的设备」里把这台移除了 | 如果是误操作，在另一台上点「添加设备」，这台重新扫加入码加入即可；本机数据都在，加入时会合并 |
| 这台设备不在同步组里了：同步组已经换了钥匙，这台设备没有拿到新钥匙（可能已被移出）… | 和上一条差不多：组换了钥匙，这台没拿到 | 点页面上的「**退出同步组，重新加入**」，再扫另一台设备上的加入码 |
| 同步组已过期，请重新加入… | 这台设备**超过 60 天没同步**，其它设备可能已经换了钥匙 | 同上：点「退出同步组，重新加入」，再扫另一台设备上的加入码 |
| 这台设备的同步文件损坏了或钥匙读不出来了（比如系统重置过锁屏），需要重新加入同步组… | 平板上保存同步钥匙的文件坏了或读不出来，**学习数据本身没事** | 在另一台设备上点「添加设备」，这台扫加入码重新加入 |
| 设备同步暂时不可用，不影响学习；可以重启 App 再试 | 同步功能这次没能启动 | 照常学习；把 App 完全关掉再打开。一直这样请联系管理员 |
| 同步节点连不上，本机照常学习，连上网后会自动补齐 | 没网，或同步服务器暂时连不上 | 检查网络，等一会儿就好 |
| 邀请码已失效，请向管理员要新的 | 管理员作废了当初那张邀请码 | 向管理员要新邀请码，在「其它」里点「重新扫邀请码」 |
| 同步空间已满，请联系管理员 | 服务器给这个同步组的空间用完了 | 联系管理员 |
| 加入码无效或已过期，请在另一台设备上重新点「添加设备」 | 加入码超过 10 分钟，或已经被用过 / 作废 | 在另一台上重新点「添加设备」 |
| 这台设备已经在一个同步组里，请先「退出同步组」… | 想加入别的同步组，但这台已经在一个组里 | 先「退出同步组」再扫 |
| 这是同步节点的管理码… / 这不是同步用的二维码… | 扫错了二维码 | 邀请码找管理员要；加入码在另一台设备的「添加设备」里 |
| 有 N 项数据来自更新版本的 App，请把这台设备也升级到最新版 | 另一台设备的 App 比这台新 | 在总入口点「检查更新」升级这台 |

### 隐私和安全
- 数据只在**你自己的设备之间**传。离开平板之前就已经**加密**了，经过同步服务器转交；服务器上只有看不懂的密文，管理员和服务器都**看不到学习内容**。
- 不需要注册账号，不收集姓名、手机号等个人信息。
- 加入新设备要两边核对四位确认码，并在已同步的设备上点确认，陌生人拍到二维码也加不进来。
- 设备丢了，就在另一台上把它「移除」，同步钥匙会自动更换。

## 十、常见问题

**换了新平板，怎么把进度带过去？**
旧平板「我的数据」→「导出全部学习数据」→ 把「下载 / 知识图谱」里的文件拷到新平板 → 新平板装好 App →「我的数据」→「选择文件…」→ 确认合并。

**两台平板（家里、学校）都在学，能合到一起吗？**
能。最方便的是用「设备同步」（第九节）：两台加入同一个同步组后自动合并，不用在同一个 Wi-Fi 下。也可以用「我的数据」把一台导出的文件导入另一台，同样是合并而不是覆盖。

**设备同步要用流量吗？两台必须连同一个 Wi-Fi 吗？**
需要能上网（Wi-Fi 或手机流量都行），不用同一个 Wi-Fi。每次只传改动的部分，数据量很小。

**同步会不会把我这台的进度冲掉？**
不会。同步是合并，不是覆盖：成绩取更好的，学习时长和骨头不会重复计算，草稿两份都保留。建组和加入前还会自动备份一份。

**换了新平板，旧平板还在，怎么办？**
旧平板在同步组里的话，新平板装好 App 后，在旧平板上点「添加设备」，新平板扫加入码加入，进度就过去了。旧平板不用了就在新平板上把它「移除」。

**所有设备都丢了 / 都卸载了，同步组里的数据能找回吗？**
不能。同步服务器上只有加密的数据，没有钥匙就打不开，管理员也打不开。所以「我的数据」导出的备份文件还是要定期存一份到电脑或网盘。

**邀请码丢了怎么办？**
已经开始同步了就不需要邀请码了，加新设备用加入码。只有提示「邀请码已失效」时才需要向管理员要新的。

**点「放到桌面」没反应？**
见第六节「把小狗放到桌面」，按页面上的手动步骤加一次就好。

**更新时提示下载失败？**
确认已联网后重试；还不行就点「用浏览器下载」，下载后直接安装（覆盖安装，进度保留）。

**小狗饿瘦了会死吗？**
不会。饿了只是没精神，学习掌握新知识点领骨头喂它就好。
