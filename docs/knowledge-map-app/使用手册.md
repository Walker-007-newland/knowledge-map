# 知识图谱 App 使用手册

这篇写给使用「知识图谱」平板 App 的学生和家长，讲怎么安装、怎么登录账号、怎么学、怎么背英语单词、怎么养小狗、怎么备份学习数据，以及换平板时怎么把学习记录带过去。

---

## 一、安装、登录和更新

### 第一次安装
1. 用平板浏览器打开家长或管理员给的下载地址（或扫二维码），下载「知识图谱」安装包。
2. 打开下载好的安装包。第一次安装时，平板可能会提示「是否允许安装未知来源应用」，按提示允许即可。
3. 装好后，桌面上会出现「知识图谱」图标。

### 第一次打开要登录
打开 App 先看到**登录页**。第一次用的学生要先注册（需要联网）：
1. 向管理员要一张「**注册码**」（一张二维码，也可以是「XXXX-XXXX-XXXX」这样一串字）。
2. 登录页点「**注册**」标签，扫码或输入注册码，起一个**用户名**（3–20 位小写字母、数字或下划线，不要用真实姓名）和**密码**（8 位以上，要同时有字母和数字），再输一遍密码。
3. 家长读一下页面上「致家长」的说明，勾选「家长已阅读上面的说明」，点「**注册并登录**」。
4. 页面会一步步显示：正在备份本机记录 → 正在验证 → 正在下载账号数据 → 正在合并 → 完成。点「开始学习」进入总入口。

已经有账号的（比如换了一台平板），点「登录」标签，输用户名和密码，点「**登录**」就行。登录过一次以后，每次打开 App 都自动进入，不用再输密码；**没有网也照常学习**。详细说明见第九节。

### 更新到新版本
- **自动提示**：联网时打开 App，如果有新版本，会弹出「发现新版本」窗口，显示当前版本、最新版本和这次更新了什么。点「立即更新」下载并安装；不想现在更新就点「以后再说」。
- **手动检查**：总入口页面最下面有「检查更新」按钮，点一下就会检查。已经是最新版时会提示「已经是最新版本」。
- 更新是**直接覆盖安装**，学习进度、错题本、小狗都会保留，不用卸载旧版。
- 如果提示「所有下载线路都连不上」，可以稍后重试，或点「用浏览器下载」，下载后手动安装（同样直接覆盖）。
- 从没有账号的旧版本升级上来时，第一次打开会到登录页。注册或登录之前，App 会**先把本机的学习记录自动备份**到「下载 / 知识图谱」文件夹，再原样并进账号，一条都不会丢（见第九节）。

> 提示：不要先卸载再安装——卸载会把这台平板上的学习数据一起删掉。实在要卸载，请先到「我的数据」导出一份备份（见第八节）；有账号的话，重新装好后登录账号也能拿回已经同步上去的记录。

## 二、总入口

登录后看到的是总入口：

- **小狗卡片**（最上面）：还没领养时写着「领养一只小狗」；领养后显示小狗的名字、等级、饱食度、骨头数和「今天学习 X 分钟」。有骨头没领时右边会出现「+N 🦴 待领取」，桌面上还没放小狗时会出现「📌 把小狗放到桌面」。点卡片进入宠物页。
- **各科卡片**：
  - 主科：数学（三年级 → 九年级）、语文（四年级 → 初三）、英语（四年级 → 初三）
  - 理科：物理（八年级上 → 九年级）、化学（九年级上 → 九年级下）
  - 生物 · 历史：生物（七年级上 → 八年级下）、历史（七年级上 → 九年级下）。内容正在按册陆续补上：目前**生物 52 个**知识点（七年级上册、七年级下册、八年级上册已补齐，八年级下册接着补）；**历史 49 个**知识点（七年级上册、七年级下册、八年级上册已补齐，八年级下册接着补）。新内容加进来后，「已掌握 X / 总数」的总数会变大，这是正常的，已经掌握的知识点不受影响
  - 其它技能：学做笔记（康奈尔 · 导图 · 错题本）
- **右上角的账号标签**：「👤 账号名 · 已同步」「⟳ 同步中」「待同步」「离线」或「⚠ 同步出错」，点它进入「账号与同步」页（见第九节）。
- **最下面一行**：版本号、「💾 我的数据」（备份和合并学习数据）、「👤 账号与同步」、「检查更新」。

## 三、各科图谱怎么学

每一科都是一张「知识地图」，一个圆点就是一个知识点，连线表示先学哪个、后学哪个。

### 看地图
- 用手指拖动地图，双指捏合放大缩小；右下角也有「+」「−」和「适应窗口」（⤢）按钮。
- 圆点的颜色表示学到哪了（地图角落有图例）：
  - 语文、英语、物理、化学、生物、历史、学做笔记：**未学**、**学习中**、**需加强**、**已掌握**；带 ★ 的是中考考频。
  - 数学：**已掌握**、**再练练**、**没掌握**。
- 顶部有搜索框，输入关键词（比如「勾股」）就能找到知识点。
- 历史页可以按「中国古代史」「中国近代史」等模块筛选，只看一段时期的知识点。

### 学一个知识点
点地图上的知识点，会打开全屏的学习页，按标签切换：

| 科目 | 标签 |
|---|---|
| 语文、英语 | 讲解、例题、写作练习、测试 |
| 物理、化学、生物、历史、学做笔记 | 讲解、例题、作图·简答（或类似练习）、测试 |
| 数学 | 动画讲解、例题、测一测 |

一般顺序是：先看讲解 → 看例题 → 做练习 → 做测试。历史的讲解里有时间轴和对比表，材料题交卷后对照参考答案自评。

### 怎样算「已掌握」
- 语文、英语、物理、化学、生物、历史、学做笔记：测试正确率达到 **80%** 就算掌握；在「入门诊断」里直接测过的也算。
- 数学：「测一测」最好成绩达到 **80%** 算掌握（50% 以上显示「再练练」）。
- 每掌握一个新知识点，就能给小狗领 3 根骨头（见第六节）。

### 主观题怎么给分（自评）
语文、英语、理科、生物历史里有些题没有唯一答案（比如简答、材料题、作文类）。交卷后页面会提示「还差最后一步：自评」：对照每道题的参考答案，把你答到的要点勾上（意思对就算，不要求字字相同），最后点「**自评完成，出成绩**」。主观题的分数按你的自评折算。请诚实自评，这样地图颜色才准。

### 顶部的其它按钮
- **入门诊断**（语文、英语）/ **诊断测试**（物理、化学）：先做一套诊断题，系统帮你判断哪些知识点已经会了，不用从头学。
- **学习路线**（语文、英语）/ **学习路径**（物理、化学）：按推荐顺序列出要学的知识点。
- **下一步学什么**（数学叫「接下来学什么 →」）：直接告诉你现在最该学哪一个。
- **错题本**（数学）：测一测做错的题会自动记进来，在错题本里订正答对就会移出。
- **备份进度**：只导出/导入**这一科**的进度。要一次备份全部科目，请用总入口的「我的数据」（第八节）。
- 物理页右上角「切换到化学 →」、生物页「切换到历史 →」可以在两科之间切换。

### 写作练习的草稿
写作练习里写的文字会自动保存成草稿，下次打开还在。

## 四、听讲解（语音朗读）

在知识点的讲解页，上方有一条播放条：
- 「🔊 听讲解」开始逐段朗读，读到哪一段就高亮哪一段；读的时候按钮变成「⏸ 暂停」。
- 「⏮」「⏭」上一段、下一段。
- 语速按钮可以在 0.8、1、1.25 倍之间切换，App 会记住你的选择。
- 切换标签或关掉学习页会自动停止朗读。
- 朗读用的是平板自带的中文语音，不用联网。

## 五、英语单词：单元单词和单词听写

英语图谱顶部有两个背单词的按钮，分工不同：
- 「**单元单词**」：App 里自带课本每个单元的单词表，选单元直接背、直接默写。
- 「**单词听写**」：自己输入词单（比如老师补充的课本以外的词），再听写。

### 单元单词

目前有**闽教版三年级到六年级的上册和下册**。其中五年级下册、六年级下册的新版课本还没出版，先用现行旧版课本的词表，册名旁标着灰色「**旧版教材**」，新版出版后会替换。七到九年级的按钮是灰的，点了会提示「词表还在整理」，以后的版本会陆续加上。

**1. 选单元**
1. 在英语图谱顶部点「**单元单词**」。
2. 上面选年级，再选「上册」或「下册」。第一次打开是四年级上册，以后会记住你上次选的。
3. 下面列出这一册的单元，每个单元显示：
   - 有多少个词；
   - 「会了 几 / 共几」的进度条；
   - 默写正确率（按这个单元里每个默过的词最近一次的结果算），没默写过显示「未默写」。
4. 勾选要背的单元，可以勾好几个，也可以点「全选」。最下面会显示「已选 几 个单元共 几 词」。
5. 勾「**只看必背**」：只背、只默课本词汇表里要求会写的词（新版课本是黑体词，旧版课本是红色词）；其它只要求认读的词不勾时也会一起出现。
6. 最下面三个按钮：「**背诵**」「**默写**」「**错词（n）**」。

**2. 背诵（卡片）**
- 一屏一张卡。上面可以选卡片正面显示什么：「看英文」「看中文」「听音」（只读发音，不显示字）。
- 点卡片翻面，看英文和中文意思。出新卡和翻面时会自动读一遍英文（选「看中文」时出卡不读，免得直接听到答案，翻面再读）；点「🔊」可以再听一遍；英文露出来以后点「🔤」打开**自然拼读**卡片（见下面「自然拼读」）。
- 下面两个大按钮：「**不会**」「**会了**」。点「不会」的词，这一轮结束前还会再出现一次。
- 可以选「课本顺序」或「打乱」，选「只背还不会的」或「全部」。
- 背完会显示这一轮的结果和还不会的词，可以「再背不会的」「去默写这些词」或「回到单元」。
- 中途点「← 返回」会问「要结束这轮背诵吗？」，已经标过「会了 / 不会」的都会保存。

**3. 默写**
- 点「默写」后，设置和听写一样：范围（全部 / 错词 / 随机抽几个）、在纸上写或用键盘输入、读法（读英文 / 英文 + 中文 / 读中文写英文）、遍数、语速、书写时间、顺序。具体操作见下面「单词听写」的第 3–5 步。
- 用键盘输入时自动判对错，大小写规则和单词听写一样（比如 Monday 写成 monday 算错，week 写成 Week 算对）。
- 写错的词会进**错词本**，再默写写对一次就移出。
- 批改页按返回键会先问「批改还没完成，要放弃这次默写吗？」，不会误退出。
- 做完后回到单元页，再按返回键就直接回英语图谱。
- 单元单词的默写设置和单词听写的设置分开保存，互不影响。
- 平板没有语音引擎时，页面顶部会提示，默写默认改为「读中文写英文」。

> 提示：课本里像「a/an」这样一条有两种写法的词，用键盘只写一个可能会被判错，在批改页把它改成对就行。

**4. 错词本**
- 最下面的「错词（n）」是所选单元里还没改正的错词。
- 右上角「**全部错词**」能看所有册的错词，按「册 · 单元」分开列出，还显示每个词错过几次。
- 错词页里可以「背错词」或「默写错词」。

> 课本以外的词（老师补充的），用下面的「单词听写」自己建词单。

### 单词听写

在英语图谱顶部点「**单词听写**」：

1. **建词单**：点「✍️ 新建词单」，用「＋ 添加一个词」逐个输入英文（中文释义可不填），填好「词单名称」后点「保存词单」。
2. **修改**：词单列表里点「编辑」可以加词、改错、删掉不要的。
3. **设置听写**：选范围（全部 / 错词 / 「随机抽」几个）、作答方式（「纸上写」或「键盘输入」）、读法（「读英文」「英文 + 中文」「读中文写英文」）、遍数（1–3 遍）、语速（正常 / 慢，点一下会试听）、书写时间（快 / 中 / 慢）、顺序（随机 / 按词单）。点「开始听写」。
4. **听写中**：屏幕只显示序号，读完自动倒计时；可以「⏮ 上一个」「🔁 再读一遍」「⏸ 暂停」「下一个 ⏭」「结束听写」。听写时屏幕不会自动熄灭。
5. **批改**：纸上写的自己对照批改后点「批改完成」；写错的词自动进错词本，下次写对一次就移出。可以「全部再听一遍」或「错词再听写」，做完点「返回词单」一次就回到词单。
6. 词单页点「← 返回」回到英语图谱。

> 发音：课本单元单词（三到六年级）都有提前录好的清晰录音，听写时直接播放，和平板无关；自建词单里课本以外的词和中文用平板自带的「文字转语音」引擎读。设置页下方会写明哪些词用录音、平板用的是什么语音引擎。如果课本以外的词听不清，建议在应用商店安装「Google 语音服务」，再到系统设置「文字转语音」里把它设为首选引擎。

### 自然拼读

把单词按「字母组合 → 音」分成小块：每块上面是字母，下面是音标（英式，和课本一样）。
- **点一块**听这一块的音；点「**▶ 拼读**」会一块一块读（读到哪块哪块变亮），再连起来读整个词；「**🔊 连读**」只读整个词。
- 红色是元音；灰色、写着「不发音」的是不发音的字母（如 knife 的 k）；黄色下划线是 magic e（cake 的 a…e：词尾 e 不发音，让 a 读长音 /eɪ/）。
- 哪里能打开：单元单词背诵时的「🔤」、错词列表和听写批改页、结果页里的「🔤 拼读」，以及知识图谱讲解里带虚线的英文单词（点一下会读出来并弹出拼读卡片）。
- 覆盖三到六年级课本单词和知识图谱讲解里的单词（约 1200 个，复数会自动补上 -s/-es）；缩写（TV、Mr.）、带撇号的（isn't）和中国地名不做拼读。

## 六、小狗

### 领养
总入口点小狗卡片 → 选品种（柴犬或哈士奇）→ 「给它起个名字」（最多 8 个字）→ 「领养它」。

### 骨头从哪来
- 在任何一科**掌握一个新知识点**，就能领 **3 根骨头**，同一个知识点只能领一次。
- 掌握时会当场弹出领骨头的提示；也可以在宠物页点「领取」。

### 照顾它
- 「🦴 喂食」：花 1 根骨头，饱食度 +20。小狗每天会慢慢变饿，饿了会没精神，但**不会生病**。
- 「🤚 摸摸」「🎾 扔球」：陪它玩，心情会变好。当天学满 10 分钟、30 分钟，心情也会更好。
- 「改名」：随时可以给小狗改名。

### 长大和装扮
- 掌握的知识点越多，等级越高。小狗会从幼犬长成少年犬、成年犬、学霸犬。
- 「装扮」标签里可以用骨头买项圈、帽子、眼镜、书包、披风等，等级越高解锁越多；买到后点一下穿戴，再点取下。
- 「成长记录」标签里能看到它的成长历程。

### 把小狗放到桌面
宠物页名字旁边点「放到桌面」。如果系统弹出「添加到桌面」的窗口，点「添加」即可。
很多平板不会弹窗（安卓不允许 App 自己把小狗放上桌面），这时页面会显示适合你这台平板品牌的**手动添加步骤**，一般是：长按桌面空白处（或双指捏合）→ 小部件 / 小组件 → 找到「知识图谱」→ 把小狗拖到桌面。也可以按提示点「打开本应用设置」，打开「桌面快捷方式」权限后再点「放到桌面」。
放好以后，重启平板小狗也会一直在桌面上，点它就能打开宠物页（还没登录时会先到登录页）。

## 七、学习统计

宠物页顶部点「📊 学习统计」，可以看到：
- **每天学习时长**：每天在各科学了多少分钟（只有在学习页面、并且最近几分钟有操作时才计时）。
- **各科进度**：每科掌握了多少知识点。
- 连续学习了多少天。

## 八、我的数据（备份、合并）

总入口最下面点「💾 我的数据」（宠物页顶部也有）。有了账号以后，换平板不用再手动导出导入（登录就行，见第九节）；「我的数据」主要用来**另存一份备份**，或者把以前的备份文件合并进来。

### 本机数据
页面最上面列出这台平板上的数据：每科「已掌握 X / 有记录 Y 个知识点」、数学错题本、草稿、学习总时长、小狗、单词听写词单、英语单元单词（「会了 N 个 · 错词 n 个」），以及这台设备的名字。

### 导出全部学习数据
点「**导出全部学习数据**」，所有科目的进度、数学错题本、作文草稿、入门诊断、学习时长、小狗、单词听写词单、英语单元单词的背默记录都会存进**一个文件**，放在平板的「下载 / 知识图谱」文件夹里，文件名类似「知识图谱-全部学习数据-日期.json」。
**恢复出厂设置、卸载之前，建议先导出一份**，并把文件拷到电脑或网盘保存。

### 导入并合并
1. 点「选择文件…」，选一个导出的文件（以前在各科「备份进度」里导出的单科文件也可以，App 自动生成的「登录前备份」「同步前备份」「导入前备份」也可以）。
2. 页面会先显示「**合并预览**」：每类数据会有什么变化，比如「语文 新增 12 个知识点记录」「数学错题 +5、−2」「小狗 骨头 45 → 52」。没有变化时会显示「没有变化」。
3. 确认没问题点「**确认合并**」；不想合并点「取消」，什么都不会改。
4. 合并前 App 会**自动先导出一份「导入前备份」**，也放在「下载 / 知识图谱」里，万一合并结果不满意可以用它恢复。

### 合并的规则（不会覆盖）
- 成绩取更好的，不会倒退；最近一次测试的结果以较新的为准。
- 学习时长、小狗骨头**不会重复计算**，同一个文件导入两次也不会翻倍；小狗等级不会因为合并而降低。
- 在一台平板上答对删掉的错题，合并后不会再冒出来。
- 两台平板同一篇草稿写得不一样时，**两份都保留**：较新的做正文，较旧的接在后面，标着「【另一台设备 … 保存的版本】」，你可以自己再删改。
- 两台平板各养了一只小狗时，合并成一只（用最早领养的那只的名字和品种）。
- 英语单元单词：同一个词在两台平板上标的「会了 / 不会」、默写对错，以较新的那次为准；错过几次不会重复计算。

### App 自动生成的备份文件
下面这些文件都在「下载 / 知识图谱」文件夹里，都可以在「我的数据」里导入：
- 「知识图谱-登录前备份-日期-时间.json」：注册、登录、合并之前自动备份的。
- 「知识图谱-导入前备份-…」：在「我的数据」合并之前自动备份的。
- 「知识图谱-同步前备份-…」：以前用「设备同步」建组、加入前自动备份的。

## 九、账号与同步（登录、换平板、几台平板自动同步）

每个学生一个账号。登录同一个账号的几台平板（比如家里一台、学校一台），学习记录、错题本、作文草稿、学习时长、英语单词记录和小狗会自动合成一份，在哪台上学都一样，**不用在同一个 Wi-Fi 下**，只要能上网。

入口：总入口最下面点「**👤 账号与同步**」，或点右上角的账号标签。

> 账号与同步只能在平板 App 里用。在电脑浏览器里打开会提示去「我的数据」用导出、导入文件的办法。

### 注册（第一次用）
1. **先向管理员要一张「注册码」**（二维码或一串「XXXX-XXXX-XXXX」）。每张注册码一般只能用一次。
2. 打开 App，在登录页点「**注册**」标签：
   - 「注册码」：扫码，或者手动输入（会自动加上「-」）。
   - 「用户名」：3–20 位小写字母、数字或下划线，**不要用孩子的真实姓名**；大写字母会自动变成小写。
   - 「密码」：8 位以上，要同时有字母和数字，不能太简单，不能和用户名一样。点「显示」可以看清输入的内容。「再输一遍密码」要和上面一样。
   - 读一下「致家长」的说明，勾选「家长已阅读上面的说明」（不勾不能注册）。
3. 点「**注册并登录**」。页面会一步步显示进度，完成后显示合并结果（比如「语文 +3、骨头 5→7」），点「**开始学习**」。
4. 本机原来的学习记录会先自动备份（见第八节），然后成为这个账号的记录，原来学过的、小狗、骨头都在。

### 登录（换平板、重新登录）
1. 登录页点「**登录**」标签，输用户名和密码，点「**登录**」。第一次在这台平板登录需要联网。
2. 页面显示：正在备份本机记录 → 正在验证密码 → 正在下载账号数据 → 正在合并 → 完成。完成后显示合并结果，点「开始学习」。
3. 如果这台平板上本来就有学习记录，登录后会和账号里的**合并**，不覆盖、成绩不倒退（规则和第八节一样）。

**提示是什么意思：**
| 提示 | 意思 | 怎么办 |
|---|---|---|
| 用户名或密码不对 | 输错了 | 再试一次；忘了密码联系管理员 |
| 这个账号已被管理员停用… | 管理员停用了这个账号 | 联系管理员；本机学习记录还在 |
| 管理员已重设你的密码，请用新密码登录 | 管理员帮你重设了密码 | 用管理员给的新密码登录；本机学习记录还在 |
| 第一次登录需要联网，请连上网络后再试 | 新平板第一次登录没有网 | 连上网再试 |
| 服务器连不上，请稍后再试 | 服务器暂时连不上 | 稍后再试；升级上来的老平板可以「先离线学习」（见下面） |
| 这台设备上有其他账号（…）的学习记录，登录后会合并到账号 … | 这台平板以前登录过别的账号 | 只有确实是同一个学生自己的记录才点「继续合并」，否则点「取消」 |
| 这台设备的同步组已升级为账号「…」，请输入密码 | 同一组的另一台平板已经注册了账号 | 用户名已填好，输那个账号的密码登录 |

同一个账号 15 分钟内密码输错 5 次，会暂停 15 分钟才能再试。

### 自动登录和离线学习
- 登录过一次以后，每次打开 App 都直接进总入口，不用再输密码。
- **没有网也照常学习**，连上网后会自动把记录同步上去。
- 只有这几种情况才需要重新输密码：新平板第一次登录、自己点了「退出登录」、管理员重设了密码、管理员停用后又启用了账号、管理员在后台移除了这台平板。

### 升级上来的老平板：先离线学习
从没有账号的旧版本升级后，如果暂时连不上服务器（比如没网），登录页会多一个按钮「**先离线学习，联网后再登录**」，最多可以先用 **7 天**（页面显示还剩几天），期间每次打开 App 都会先到登录页。联网后回到登录页注册或登录，本机记录会全部进入账号。7 天用完后必须联网登录。全新安装、本机没有记录的平板没有这个按钮。

### 以前用「设备同步」的平板
以前几台平板用邀请码、加入码组成同步组的，升级后：
- 其中一台先注册账号（登录页会提示「这台设备已在同步组里：注册后，同组的其它设备升级 App 后输入这个账号的密码就能登录，数据照旧一致」）。
- 其它几台升级后打开，登录页的**用户名已经自动填好**，输密码点「登录」就行，数据不动。
- 还没升级的平板照常和升级过的同步，不会断掉。
账号登录后不再需要邀请码、加入码和 Wi-Fi 配对，这些按钮不再显示。

### 「账号与同步」页
- 最上面显示「👤 账号名」，下面是**服务器**地址。「修改」和「在家里 Wi-Fi 里找」只在管理员说「服务器搬家了」时才用：按管理员给的地址改，或者在家里 Wi-Fi 里自动查找。平时不要动。
- 「**退出登录**」：会先问「退出后本机学习记录保留，需要重新输入密码才能进入」。退出后回到登录页，本机记录都在。
- 状态一行：「已同步 · 今天 时:分」「有改动等待同步」「同步节点连不上，本机照常学习，连上网后会自动补齐」等。
- 「**🔄 立即同步**」：想马上同步时点。
- 「**我的设备**」：登录这个账号的所有平板，标着「本机」的是你手上这台，每台都写着「上次收到它的改动」的时间。设备丢了、不认识的设备要移除，请联系管理员在后台处理。

### 平时怎么同步
- 不用手动操作：打开 App、回到总入口时都会自动同步，在前台每隔一段时间也会同步一次。
- 一台平板上学完，另一台**回到总入口**后，一般几十秒内就能看到变化，并弹出一行提示，比如「从『某某平板』同步：语文 新增 1 个知识点记录，已掌握 6 → 7；小狗 骨头 20 → 23」。
- 两台平板连在**同一个 Wi-Fi** 下时，还会直接互相传，几秒钟就到，服务器连不上也能同步。
- 没网的时候照常学习，连上网后会自动补齐。

### 总入口右上角的账号标签
| 标签 | 意思 |
|---|---|
| 👤 账号名 · 已同步 | 本机的改动已经同步好了 |
| 👤 账号名 · 同步中 | 正在和别的平板交换改动 |
| 👤 账号名 · 待同步 | 本机有新的改动还没送出去，稍后会自动同步 |
| 👤 账号名 · 离线 | 没网，或服务器连不上。本机照常学习，数据不会丢 |
| 👤 账号名 · 同步出错 | 这次没同步成功。点标签进「账号与同步」看原因 |

### 忘记密码
登录页点不了「找回密码」——密码只能由**管理员**重设。联系管理员，管理员会给你一个新密码；之后这个账号的所有平板打开时会回到登录页，提示「管理员已重设你的密码」，用新密码登录即可，本机的学习记录不会丢。

### 隐私和安全
- 只收用户名和密码，不收手机号、真实姓名。
- 学习记录在平板上**加密**后才上传，经服务器转交；服务器上只有看不懂的密文。密码不会在网络上明文传输，平板上也不保存密码。
- 为了孩子忘记密码时能找回记录，管理员保留一把「恢复密钥」，必要时可以解开本账号的学习记录，只用于重设密码、找回数据（注册页的「致家长」说明里有写）。
- 平板丢了：联系管理员在后台移除那台设备或停用账号，它下次联网就会退到登录页，拿不到新的记录。

## 十、常见问题

**换了新平板，怎么把进度带过去？**
新平板装好 App，登录页输入同一个用户名和密码，点「登录」，等进度走完就都过来了。旧平板还在的话继续用也行，两台会自动同步。

**两台平板（家里、学校）都在学，能合到一起吗？**
能。两台登录同一个账号就自动合成一份，不用在同一个 Wi-Fi 下。也可以用「我的数据」把一台导出的文件导入另一台，同样是合并而不是覆盖。

**同步要用流量吗？两台必须连同一个 Wi-Fi 吗？**
需要能上网（Wi-Fi 或手机流量都行），不用同一个 Wi-Fi。每次只传改动的部分，数据量很小。在同一个 Wi-Fi 下会更快。

**同步会不会把我这台的进度冲掉？**
不会。同步是合并，不是覆盖：成绩取更好的，学习时长和骨头不会重复计算，草稿两份都保留。注册、登录前还会自动备份一份。

**升级到有账号的版本后，原来学过的还在吗？**
在。注册或登录之前 App 会先自动备份到「下载 / 知识图谱」，再把本机记录原样并进账号。万一有问题，可以在「我的数据」里导入那份「登录前备份」。

**忘记密码了怎么办？**
联系管理员重设，本机记录不会丢（见第九节「忘记密码」）。

**没有网能打开 App 吗？**
登录过的平板可以，照常学习，联网后自动同步。只有新平板第一次登录、注册时必须联网。

**注册码丢了 / 用过了怎么办？**
注册码只在注册时用一次，注册好以后就不需要了。还没注册就丢了，向管理员再要一张。

**所有平板都丢了 / 都卸载了，记录能找回吗？**
能。新平板登录同一个账号，上次同步过的记录都会下载回来。保险起见，「我的数据」导出的备份文件还是建议定期存一份到电脑或网盘。

**点「放到桌面」没反应？**
见第六节「把小狗放到桌面」，按页面上的手动步骤加一次就好。

**更新时提示下载失败？**
确认已联网后重试；还不行就点「用浏览器下载」，下载后直接安装（覆盖安装，进度保留）。

**小狗饿瘦了会死吗？**
不会。饿了只是没精神，学习掌握新知识点领骨头喂它就好。
