# 中考数学知识地图 · 使用说明

## 怎么打开

双击 `index.html`，用浏览器打开即可（推荐 Chrome 或 Edge）。不需要联网。

## 怎么给学生

把整个 `math-map` 文件夹拷给学生（U 盘、网盘、压缩包都可以），让学生双击里面的 `index.html`。
**只拷 index.html 一个文件是打不开内容的**，`js` 文件夹必须一起带上。

## 学生怎么用

1. 点顶部的“接下来学什么 →”，会自动推荐下一个该学的知识点；也可以在地图上直接点。
2. 每个知识点：先看“动画讲解”并动手操作，再看“例题”（一步一步揭示），最后“测一测”。
3. 测试答对 80% 以上，地图上这个知识点会亮起绿点；没掌握时会提示先复习哪些前置知识。
4. 测试里做错的题自动收进顶部的“错题本”（红色数字是还没订正的题数）。在错题本里重新做对，或者回到知识点的测试里做对，这道题就会移出；再做错会记下次数。

学习进度和错题本保存在学生自己电脑的浏览器里。换电脑、换浏览器或清除浏览器数据后，进度会从头开始。

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 打开用的页面（由 `page.html` 生成，不要直接改它） |
| `page.html` | 页面结构和样式 |
| `js/nodes.js` | 72 个知识点的清单和前后关系 |
| `js/lessons*.js` | 讲解、例题、测试题内容 |
| `js/anims*.js` | 互动动画 |
| `test.html` | 自检页：打开后自动检查所有内容和动画，标题显示“全部通过”即正常 |
| `AUTHORING.md` | 修改或新增内容的编写规范 |

改了 `page.html` 之后，需要运行 `build.sh` 重新生成 `index.html`。只改 `js` 里的内容则不需要。
