# 补题说明：例题和测试题要覆盖知识点的每个要点

用户要求：每个知识点的例题、测试题数量不设上限，以“覆盖讲解里的所有要点”为准（取代原来“3 道例题、6 道测试题”的规定）。

先通读 `AUTHORING.md`（字段、题型、HTML 写法、质量要求都以它为准），再参考你负责文件里现有题目的风格。只改 `examples` 和 `quiz`，不改讲解、动画和其他文件。

## 你的任务（只改分配给你的那一个 lessons 文件）

对文件里的**每一个知识点**：

1. **列要点**：通读 `goal`、`fj`、`sections`、`pitfalls`，把每个独立要点列出来：每个概念/定义、每条性质或法则、每个公式及其变形、每种常考题型/解题方法、每条 pitfall（易错点）。
2. **对照现有题**：看每个要点有没有例题、有几道测试题。
3. **补题**，直到：
   - 每个要点至少有 **1 道例题**（`{ q, steps, ans }`，2～4 步逐步揭示；一道例题最多覆盖两个紧密相关的要点）；
   - 每个要点至少有 **2 道测试题**（每条 pitfall 和中考高频点 3 道），选择、填空混合；
   - 总数不设上限，但同一要点的几道题要换数据、换情境、换问法，不要只改数字。
4. 原有题保留（发现错误就顺手改对）。

## 质量要求（严格）

- **数学必须正确**：每道题自己算两遍，答案和解析一致；选择题只有一个正确选项，正确答案位置分散。
- 填空答案只用整数、小数、分数（写成 3/8）、负数（写成 -4），系统按数值比较；要填 √、π、字母式、单位、汉字的题改成选择题。
- 解析（`why`）说清为什么，不要用“选 A”指代选项（选项会打乱时就会错位）。
- HTML 写法照 AUTHORING.md：`<i>x</i>`、`<sup>2</sup>`、`${fr(1, 2)}`、负号 `−`、乘号 `×`。
- 难度贴合该年级；小学知识点用三年级学生能读懂的口语；按人教版教材范围，不超纲；不编造某年真题。

## JS 语法安全

长内容用反引号模板字符串（文件里已有 `${fr(...)}` 插值的写法照用，其他地方不要出现 `${`）；单引号字符串里的撇号要转义。改完用 Python 检查括号平衡，并重读改动区域。完成后可打开 `test.html`（自检页）确认“全部通过”。
