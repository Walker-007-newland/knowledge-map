# 补题说明：例题和测试题要覆盖知识点的每个要点

用户要求：每个知识点的例题、测试题数量不设上限，以“覆盖讲解里的所有要点”为准。现在大多数知识点是 2–3 道例题、7 道测试题，很多要点没考到。

## 你的任务（只改分配给你的那一个文件）

对文件里的**每一个知识点**：

1. **列要点**：通读 `tip` 和 `learn`，把讲到的每个独立要点列出来。一条规则、一个变化规律（如 -es 的几种情况各算一个）、一个易错点、一个固定句型、一组需要辨析的词、一种题型技巧，都算一个要点。词汇话题类：每个小类词表 + 易错拼写 + 句型各算一个要点。
2. **对照现有题**：看每个要点有没有例题、有几道测试题。
3. **补题**，直到：
   - 每个要点至少有 **1 道例题**（例题带详细解析，是“教”的）；
   - 每个要点至少有 **2 道测试题**（易错点、中考高频点 3 道），题型尽量多样（选择、填空、听力 `say`、改错、句型转换等）；
   - 测试题总数不设上限，但不要为了凑数出重复的题——同一要点的几道题要换语境、换考法。
4. 原有的题保留（除非发现错误，就顺手改对）。新题按讲解的顺序插在合适位置即可（测试时会打乱）。
5. 题型技能节点（`s-` 开头）：要点是每一步解题方法和每种设问类型（如细节题里的“数字计算”“同义替换”“图表信息”）；可以新增原创短文 `passages`，每种设问类型至少 2 题。有 `practice` 的节点，若讲解提到的文体/话题没有练习，补一个写作练习。

## 质量要求（和之前一样，严格执行）

- 每道选择题**只有一个**说得通的正确选项；逐个检查干扰项。
- 填空题提示要让答案唯一（给首字母、括号给词、说明“填一个词”等），`answer` 数组列出所有可接受写法（缩写/全写、英美拼写、数字/单词）。
- `explain` 用中文讲为什么，**不能出现 A/B/C 字母**（选项会打乱）。
- 难度符合该知识点的年级；英文自然地道；材料原创，不抄真题。
- 字段格式见 `data/modules.js` 顶部注释；风格参照 `data/grammar.js`。

## JS 语法安全（没有 Node.js）

长文本用反引号模板字符串，内容里不能出现反引号或 `${`；单引号字符串里的撇号要写成 `\'` 或改用双引号。改完后用 Python 检查括号平衡（忽略字符串内的字符），并重新读一遍改动过的区域。
