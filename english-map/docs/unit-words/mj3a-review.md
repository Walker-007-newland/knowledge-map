## 拼写校验

`python -X utf8 docs/wordlists/unit_check.py docs/unit-words/mj3a.json` 输出：

```
# mj3a：共 178 个词条，词表外 2 个
- `I'm` 专有名词？（u1 I'm （I am）我是）
- `woof` （u1 woof （狗叫声）汪！）
```

逐个说明：

- `I'm`：I am 的缩写，课本原文就是 I’m=I am（图 81，细体），按统一写法保留缩写作为词头。不是专有名词，拼写没有问题（大写 I 是代词本来的写法）。
- `woof`：拟声词「（狗叫声）汪」，课本原文如此（图 81 右栏，细体），不在各词表里属正常，拼写正确。
