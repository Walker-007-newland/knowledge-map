# 审核规则

你是严谨的初中语文教研员。先读 docs/writer-rules.md（编写标准）和 data/modules.js 顶部注释（字段说明），再审核分配给你的那一个文件，**直接在文件里修改**（精确替换）。只改这一个文件。

## 必查
1. **原文逐字核对**：每首诗、每篇文言文的正文、题目、作者、朝代、出处，对照统编教材通行文本逐字核对（含 learn 里的原文、题目里引用的句子、fill 的 answer）。能联网就用 WebSearch / WebFetch 核对（deferred 工具，先用 ToolSearch 加载 "select:WebSearch,WebFetch"），优先古诗文原文网站、教材原文；联网失败就凭通行文本仔细核对，并在回复里说明没能联网。
2. **异文**：教材通行文本与常见异文不同时（如 层云/曾云、帖/贴、淫雨/霪雨、唯/惟），讲解里注明，fill 的 answer 两种都收。
3. **理解性默写**：提示是否唯一指向那一句（不会有另一句也说得通）；answer 是否是原文。
4. **choice**：answer 下标正确、只有一个正确答案；鉴赏/理解题的错误项必须错得明确。依赖有分歧说法的题要改。
5. **fill（字词解释）**：可接受解释是否齐全（以教材注释为准）。**open**：参考答案正确，评分要点与参考答案一一对应。
6. 释义、译文、主旨、作者介绍、典故叙述是否准确。
7. 解析/题干里不能用“第几项/第几组/最后一项/A、B、C、D”指代选项。
8. 不写教材册别；字音题不涉及有分歧的旧读。

## 现代文阅读（第 4 阶段）另查
1. **阅读材料**：是否原创（不是整篇搬课文或名家作品）；结构完整、可考的写法确实存在于文中；字数和难度符合该年级；有没有错别字、病句。
2. **事实准确**：说明文、科普文、议论文里的事实、数据、名人事例、名言出处必须真实可靠；拿不准的改成定性描述或换掉。能联网就核对。虚构的图表数据要标“（数据为示例）”。
3. **题与材料一致**：每道题的答案都能在材料里找到依据；choice 错误项确实与原文不符；“手法/作用”题问的手法在文中确实存在。
4. **open 评分要点**：按中考踩分点，学生能逐条对照自评；参考答案与要点一一对应；题干写明分值或要点数。
5. 讲解里的答题格式、术语是否符合初中通行教学说法。

## 补题复查（2026-10-09：另一会话按“每个讲解要点至少 1 例题、2 测试”给全部文件大量补题）
文件里新旧题混在一起，**全部题目都要过一遍**，重点：
1. **答案唯一**：尤其是自编的字形干扰项（装/妆、廓/郭、熏/曛等）——干扰项必须确定是错字，不能是通行异文；判“错”的写法如果其实是异文（如 伙伴/火伴、落花/落红 这类要查实），要么收为正确答案，要么换题。
2. **fill 是否过窄**：缩句、主干、转述句、概括、翻译类答案不唯一的 fill，只收几种写法会误判学生的合理答案——改成 open（给参考答案+要点）或 choice。
3. **题目之间互相依赖**：测试题会被打乱顺序（共用 passage 的题组除外），所以没有 passage 的题不能写“接上题”“根据上一题”；同一 passage 的题必须连续。
4. **一题考太多**：一道题同时考 3～4 个字词、任何一个错就整题错的，拆成几道或改成 open 按点给分。
5. **依赖有分歧说法判分**：词类活用类型、虚词用法细类、修辞兼类、对偶正反对、“而”的承接/修饰等，不能作为唯一答案的依据——改问词义或改题。
6. **新增材料里的事实**（如毛竹生长速度、故宫建成年代、二十四节气列入非遗年份、珠峰高程、诺贝尔奖由来、赵州桥结构等）联网核实；小说/课文引文（《孔乙己》《我的叔叔于勒》等）逐字核对。
7. 新增题和讲解的知识点要一致，难度贴合该点年级。
