# 补题说明：例题和测试题要覆盖知识点的每个要点

用户要求：每个知识点的例题、测试题数量不设上限，以“覆盖讲解里的所有要点”为准（取代原来“例题 2～3 道、测试 6～10 道”的规定）。

先通读 `docs/writer-rules.md`（所有编写规则、题型、样式、硬性规则都以它为准）和 `data/modules.js` 顶部注释，再参考你负责文件里现有题目的风格。

## 你的任务（只改分配给你的那一个文件；不要改 html、js、其他数据文件）

对文件里的**每一个知识点**：

1. **列要点**：通读 `tip` 和 `learn`，把讲到的每个独立要点列出来。
   - 字词/语法修辞：每条规则、每类易错字音字形、每种病句类型、每种修辞及其作用答法，各算一个要点。
   - 古诗默写：**每首诗**算一个要点（每首至少 2 道默写：直接默写 + 理解性默写；名篇名句 3 道）；诗中的易错字、主旨情感也要考到。
   - 文言篇目：每个重点实词/虚词/通假字/古今异义/一词多义/词类活用、每个重点句翻译、每个内容主旨/写法点、每句必背名句，各算一个要点。
   - 现代文阅读/题型技能：每种设问类型、每条答题格式、每个常见失分点各算一个要点；可新增**原创**阅读材料（passages），每篇配多道题。
   - 综合性学习/写作：每种题型、每个答题要求各算一个要点；讲解提到的写作类型没有 practice 的，补一个写作练习。
2. **对照现有题**：看每个要点有没有例题、有几道测试题。
3. **补题**，直到：
   - 每个要点至少有 **1 道例题**（带详细解析；一道例题最多覆盖两个紧密相关的要点）；
   - 每个要点至少有 **2 道测试题**（易错点、中考高频点 3 道），题型多样（choice / fill / open）；
   - 总数不设上限，但同一要点的几道题要换角度、换考法，不要重复。
4. 原有的题保留（发现错误就顺手改对）。

## 质量要求（严格执行 writer-rules.md 的硬性规则）

- 古诗文原文逐字准确，以统编教材通行文本为准；有异文的 fill 两种都收。
- 理解性默写的提示必须唯一指向那一句。
- choice 只有一个正确答案；解析和题干不能用“第几项/A、B、C”指代选项。
- open 题：ref 参考答案 + points 评分要点一一对应，题干写明分值或要点数。
- 现代文材料一律原创；说明文、议论文里的事实数据必须真实可靠。
- 字音题不涉及有分歧的旧读；不标“某年中考真题”；不写教材册别。

## JS 语法安全

字符串用单引号，HTML 长内容用反引号模板字符串；字符串里只用中文引号“”‘’，不要出现未转义的英文单引号；模板字符串里不出现反引号和 `${`。改完用 python 检查括号配对、answer 下标范围，并重读改动区域。

## 汇报（200 字以内）

每个知识点：要点数、例题 改前→改后、测试题 改前→改后；拿不准的地方。

## 项目会话补充的约定

- 有 passage 的题组不打乱题目顺序（选项仍打乱）；同一 passage 的题要连续放在一起。
- fill 比对忽略空格和标点（只看字），所以**标点题只能出 choice**；answer 列全合理写法和异文（层云/曾云、帖/贴、淫雨/霪雨、唯/惟、红纱/红绡、疲弊/疲敝）。
- 字音以 1985 年《普通话异读词审音表》和课本注音为准；说服、一骑、石径斜、叶公等有分歧的字不出唯一答案题。
- 有分歧的分类（虚词用法、活用类型、修辞兼类、语序等）不拿来判分。
- 自检：遍历 KG.nodes 查 choice 下标范围、fill 非空、open 有 ref 和 points、passage 键存在、explain 里无 /第[一二三四]项|第[一二三四]组|最后一项|[A-D]\s*项/。
