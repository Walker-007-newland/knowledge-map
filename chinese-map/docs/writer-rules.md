# 内容编写规则（写手与审核都按此执行）

项目：福建中考语文知识图谱，给一个孩子自用，统编版教材，小学四年级到初三。静态网页，内容在 data/*.js 里用 `KG.nodes.push(...)` 追加。

## 先读
1. data/modules.js 顶部注释：字段格式和三种题型（choice / fill / open）、passages 用法。
2. 同模块已定稿的样板：data/sample-a.js（s-moxie-7a 是默写样板，w-intro / w-fanyi 是文言样板，s-jianshang 是鉴赏样板）。照它们的风格、深度、HTML 写法来写：tipbox、`<div class="rhyme">` 口诀、`<table class="tbl">`、`<p class="warn">`、古诗 `<div class="poem ex"><p class="poem-title">题</p><p class="poem-author">［唐］作者</p><p>一句，一句。</p>…</div>`、文言 `<p class="ex">原文<span class="zh">译文</span></p>`、加点字 `<span class="dot-em">字</span>`、`<span class="kv">`。

## 每个知识点
- tip：一句话中考提示。不编造分值，不写“某年考了什么”。
- learn：面向学生、口语化。
- examples：带详细解析；**数量不设上限，讲解里每个要点至少 1 道**（一道例题最多覆盖两个紧密相关的要点）。
- tests：**数量不设上限，每个要点至少 2 道（易错/高频点 3 道）**，见 docs/coverage-brief.md。题目难度贴合该年级。
- open 主观题：ref 参考答案 + points 评分要点（每点 1～2 分），要点与参考答案一一对应，学生能对照自查。

## 默写类知识点（gushi 模块的“默写·…”和“小学古诗·…”）
- learn：每首诗完整原文（poem 排版）+ 作者朝代 + 两三句“理解”（写了什么、表达什么情感、名句好在哪）+ `<p class="warn">易错字：…</p>`。
- tests：以 fill 为主——直接默写（给上句写下句或给下句写上句）和理解性默写（给情境提示，写出对应诗句）各占一半；可加 1～2 道 choice（诗句理解、情感判断）。每首诗至少考到一次。
- 理解性默写的提示必须能唯一指向那一句，避免两句都说得通。
- fill 的 answer 写成原文（含标点也可以，比对时忽略标点空格），有教材通行异文的把两种都列上。

## 文言篇目类知识点（wenyan 模块的 w-p-…）
- learn：完整原文（分段，长文可分几段 `<p class="ex">原文<span class="zh">译文</span></p>`，每段附译文）+ 作者出处（文学常识）+ 重点字词表（实词、虚词、通假字、古今异义、一词多义、词类活用）+ 重点句翻译 + 内容主旨与写法 + 必背名句。
- tests：解释加点词（fill，列全合理解释）、词义相同/不同（choice）、句子翻译（open，按关键词给分）、内容理解（choice / open）、名句理解性默写（fill）。数量按覆盖要点定，不设上限。

## 现代文阅读类知识点（xiandai 模块，第 4 阶段）
- 样板：data/sample-b.js 里的 x-gaikuo（记叙文，passages 用法）和 x-shuoming（说明文）。照它们的深度和写法来写。
- learn：讲清“是什么、怎么认、怎么答”，**每个点都要给答题格式**（如“手法 + 具体内容 + 作用（内容上…结构上…情感上…）”），配短例文片段演示，列出常见失分点。
- **阅读材料一律原创**，不整篇搬课文或名家作品；可以短引（一两句）课文名句来举例。每个点至少 1 篇 passages（记叙文、散文、小说 400～900 字；说明文 400～700 字；议论文 500～800 字），tests 中至少 4 道题共用它。材料要像中考文章：有完整的结构、有可考的写法，适合该年级。
- 说明文、科普文、议论文里的**事实、数据、人物事例必须真实准确**：只用公认可靠的常识；拿不准的具体数字不写，或改成定性描述；名人事例只用广为人知、确有其事的。非连续性文本里的图表、调查数据可以虚构，但要标“（数据为示例）”。
- tests：choice（理解、判断手法/作用）+ open（主观题为主，给 ref 参考答案 + points 评分要点，要点按中考“踩分点”给，学生能逐条对照自评）。open 题题干写清分值或要点数（如“（3 分）”“从两个方面分析”）。
- choice 的错误项要错得明确（与原文不符、张冠李戴、以偏概全、无中生有），解析指出错在哪。

## 硬性规则
- **古诗文原文逐字准确**，以统编教材通行文本为准；作者、朝代、出处准确。教材有改字或通行异文时（如“淫雨/霪雨”），讲解里注明，fill 答案两种都收。拿不准的一律不用。
- 不写教材册别（新修订版位置在变），可以写年级。
- 不标“某年中考真题”；文件开头注释写本阶段和组名，如“// 第 4 阶段 P 组：记叙文基础”。
- choice：**只有一个正确答案**，其他选项确定错误；answer 是下标（从 0 开始），写完逐题核对。有争议的分析（词性、用法有分歧的）不出题。
- 选项在页面上会被打乱：解析和题干里**不能用“第几项/第几组/最后一项/A、B、C、D”指代选项**，直接引用内容。（材料中编号的句子、段落①②③可以照用。）
- 字音以 1985 年《普通话异读词审音表》和课本注音为准；“斜、骑、说（shuì）、叶（shè）”等古诗旧读/修订有分歧的字，不出唯一答案的读音题。
- 不标“某年中考真题”。
- 文件开头写注释“// 第 3 阶段 X 组：……”，然后 `KG.nodes.push( 节点1, 节点2, ... );`。
- JS 语法：字符串用单引号，HTML 长内容用反引号模板字符串；字符串里只用中文引号“”‘’，不要出现未转义的英文单引号；模板字符串里不出现反引号和 `${`。
- 写完通读一遍，逐题检查答案唯一性、下标、引文；用 python 检查括号配对、answer 下标范围。
